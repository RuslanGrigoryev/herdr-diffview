herdr-diffview

A live diff viewer for Herdr — run it in a pane next to a coding agent (Claude Code, Codex, …) and watch the working tree change in real time. Syntax-highlighted, word-level diff, live agent status, all in your terminal.

Why

Live, not on-demand

An inotify watcher debounces every save and refreshes the diff automatically — no re-running a command.

Follows the agent

Auto-jumps to whichever file the agent just touched, and shows its Herdr status (working / idle / blocked) in the header.

Real syntax highlighting

Pygments lexing per language, word-level diff highlighting within changed lines, 14 dark themes to cycle through.

Worktree-aware

Correctly tracks git worktree checkouts and detects the right agent pane when several run at once.

Install

Recommended: pipx — puts the herdr-diffview command on your PATH globally, callable from any directory. 

brew install pipx
pipx ensurepath

git clone https://github.com/RuslanGrigoryev/herdr-diffview.git
cd herdr-diffview
pipx install .

bToggle diff vs. base branch
